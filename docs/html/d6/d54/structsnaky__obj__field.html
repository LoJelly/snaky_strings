Detailed Description

Represents a single field within a struct/object.

The values in the snaky_obj_field are in the order of: name, data type, offset, size, count.

◆ count

size_t snaky_obj_field::count

The number of elements within the field. If the field is a single value, then this should be 1. If the field is an array, then this should be equal to the total number of elements within that array excluding nested arrays.

Important
If this value is 0 when the snaky_parse_object(...) function is called, it is automatically set to 1 by default.

◆ data_type

snaky_data_type snaky_obj_field::data_type

The data type of the attribute and value.

Important
Do not use SNAKY_ARRAY, even if the object's field is an array. The data type should always reflect the underlying type; so if it's an integer array, it should be SNAKY_INT.
